Data sources

About this data: eco-cost figures are based on Idematapp / ecocostsvalue.com reference data (2020 excerpts), covering common materials, processes, energy, and transport modes — use the "Custom line item" field for anything not listed. Method: single-indicator eco-costs (euros), the prevention-cost approach.

About the carbon / water / energy / recycled-content figures: these are representative reference values compiled from general public LCA literature, not from the same certified source as the eco-cost figures above. Treat them as indicative, and use the custom line fields for measured or certified numbers where precision matters.
